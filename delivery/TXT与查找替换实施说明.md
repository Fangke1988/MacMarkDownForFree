# TXT 与查找替换

## 范围与验收

1. 文件支持：接入 `.txt` 的打开、保存、另存为、目录列表、系统文件关联；TXT 使用纯文本编辑。验证中文路径、原样读取、UTF-8 / BOM / CRLF 保存和 Markdown 回归。
2. 自动换行：为 TXT 和 Markdown 源码提供持久化开关，关闭后可水平滚动。验证开关不会改变内容、光标和撤销记录。
3. 查找替换：在当前文档原文中查找，支持上一个、下一个、单次替换和全部替换；定位时使用文本 / 源码视图保证位置准确。验证中文、重复匹配、空替换、撤销和末尾循环。
4. 全文结果：底部显示所有匹配的行号、列号和上下文，可点击定位、折叠、展开、清空；编辑与替换后更新结果，切换标签分别保留。全文范围是当前文件，不包括其他文件或文件夹。
5. 交付：完成前端检查、浏览器交互和真实 WKWebView 集成验证，重新构建 `delivery/MarkDownEditor.app`，记录通过项与未验证边界。

## 使用方式

- 打开：`⌘O` 可选 Markdown / TXT，文件夹侧栏与 Finder 文件关联也支持 TXT。
- 保存：`⌘S`；`⇧⌘S` 另存为，可在保存窗口下方选择 `.md` / `.markdown` / `.txt`。另存 TXT 保留文档原文，不移除 Markdown 符号。
- 自动换行：菜单「视图 → 自动换行（TXT / 源码）」，自动记住选项，已打开的窗口和标签同步应用。
- 查找替换：工具栏放大镜或 `⌘F`；`⌥⌘F` 聚焦替换框，`⌘G` / `⇧⌘G` 定位下一处 / 上一处。
- 全文结果：点击「全文查找」或 `⇧⌘F`；底部显示 `行:列` 和文本片段，点击一项选中原文。Markdown 会切换至源码定位。
- 结果控制：点击「查找结果」标题折叠 / 展开；「清空结果」仅清除列表；关闭顶部查找栏仍保留底部结果。
- 替换：默认不区分大小写，可勾选区分；按字面文本匹配，替换框留空可删除匹配内容。全部替换可一次撤销。

TXT 沿用应用现有 UTF-8 支持；原有 BOM 与 CRLF 在保存时保留。当前不提供跨文件夹内容查找或正则表达式查找。
