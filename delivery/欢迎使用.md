# 让文字，回到写作本身

这是你的本地 Markdown 工作台。打开一个文件夹，在左侧浏览文档；切换到**大纲**，按章节阅读。

> 文件始终保存在你的磁盘上。无需账号，核心编辑和预览功能可离线使用。

## 从阅读到编辑

点击顶部的 **编辑**，或双击正文，在当前位置开始修改。需要调整 Markdown 语法时，切换到 **源码**。

| 操作 | 快捷键 |
| :--- | :--- |
| 阅读与编辑切换 | ⌘E |
| 插入或编辑链接 | ⌘K |
| 查找与替换 | ⌘F |
| 立即保存 | ⌘S |
| 导出 PDF | ⌘P |

## 插入内容

通过顶部的 **＋** 插入图片、表格、超链接、代码、公式或图表。

- 图片可以拖入或从剪贴板粘贴，自动放进文档旁的 `assets` 文件夹。
- 表格单元格可以直接输入；选中后可增删行列、设置对齐。
- 双击图片、公式或代码块，可以修改其属性或内容。
- 超链接支持网页、相对文件路径，以及[当前文章章节](#从阅读到编辑)。

## 技术表达

代码块保留语言信息，阅读时可直接复制。

```swift
let message = "你好，Markdown"
print(message)
```

公式既可以出现在行内，例如 $E = mc^2$，也可以独立成行：

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

## 安心保存

停止输入约一秒后自动保存。未命名文档保留恢复草稿，可从 **File → 恢复草稿** 继续。

如果其他程序同时修改了文档，应用会暂停覆盖，并让你选择保留本地副本或加载磁盘版本。

含 Front Matter、原始 HTML 或不能安全转换的扩展语法的文档，会自动使用源码编辑，保留原文。

## 适合你的外观

顶部半圆按钮可以选择**浅色**、**深色**或**跟随系统**。导出 PDF 使用适合打印的浅色样式。
